# Tokmira 品牌标志

设计源文件：[Figma · Tokmira 品牌标志](https://www.figma.com/design/IYMzCrQfYouN8p8SLMoAja?node-id=57-1447)

标志以一对镜像折面组成字母 M，中央保留切口。沿用产品的蓝色识别。

## 文件用途

- `tokmira-mark-blue.svg`：浅色背景上的独立符号，颜色 `#2F6AE0`。
- `tokmira-mark-dark.svg`：深色背景上的独立符号，颜色 `#5B8CFF`。
- `tokmira-mark-mono.svg`：墨色单色符号，颜色 `#1A1B1F`。
- `tokmira-mark-white.svg`：白色反白符号。
- `tokmira-lockup-light.svg`：浅色背景横版标志。
- `tokmira-lockup-dark.svg`：深色背景横版标志。
- `tokmira-lockup-white.svg`：白色横版标志。
- `tokmira-app-icon.svg`、`tokmira-app-icon-1024.png`：圆角方形应用图标。
- `tokmira-logo-board.png`：设计展示与尺寸检查图。

## 使用说明

SVG 字标已转为路径，使用时不依赖字体安装；Figma 中保留可编辑文字，字体为 Manrope ExtraBold。等比缩放，保留中央切口，不拉伸、不添加描边。建议独立符号最小显示尺寸为 16 × 16 像素，横版标志建议至少 120 像素宽。

Figma 提供 Primary、Monochrome、Inverse 三种组件变体，并复用现有 Color v2 品牌变量，支持浅色和深色模式。已查看深浅色效果与 16、24、32、48、80 像素符号样例。

本目录为设计交付文件。程序主页侧栏、macOS 菜单栏、应用打包图标已接入本设计；官网构建会复用应用图标源文件。macOS 菜单栏使用黑色透明模板，由系统自动着色；打包图标保留 100/1024 的外边距。
